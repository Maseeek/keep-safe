# Product direction

Keep Safe should make an agent's request for human login quick enough to handle away from a desk. The first useful outcome is a reliable handoff that returns an authenticated browser to the waiting agent.

## Free initial release

The developer runs the bridge on their own computer. The mobile frontend is hosted on Vercel and can also be self-hosted. No paid account or AI API is required by the app. Source stays private while the owner evaluates release readiness.

## A path to revenue

Validate repeated use of the free workflow before adding billing. A future paid service could provide a managed relay, easier device pairing, team approval routing, revocable access, and privacy-preserving audit records. Those are product hypotheses, not implemented features or current security guarantees.

Measure onboarding completion, successful handoffs, time from request to returned control, repeated weekly use, and the reasons users abandon a handoff. Initially gather feedback directly; do not add tracking pixels or send credential-bearing page data to analytics.

Pricing, a public licence, hosted browser infrastructure, and payment collection require later product decisions. The current £0 budget does not authorize enabling paid infrastructure or accepting customer payments.
